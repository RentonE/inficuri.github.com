# 任务档案（Task Archive）

本目录用于对本仓库的所有任务进行分类建档。每个任务完成后，在对应分类目录下新增一份归档文档，并在下方索引表登记。

## 分类目录

| 目录 | 分类 | 说明 |
|------|------|------|
| `research/` | 调研查询 | 信息查询、资料调研、问题解答类任务 |
| `feature/` | 功能开发 | 新增功能、新页面、新文章等开发类任务 |
| `fix/` | 问题修复 | Bug 修复、错误更正类任务 |
| `docs/` | 文档维护 | 文档撰写与更新类任务 |
| `chore/` | 日常维护 | 依赖升级、配置调整、清理等杂项任务 |

## 归档规范

- 文件命名：`YYYY-MM-DD-任务简称.md`（日期为任务完成日）
- 每份档案包含：任务描述、分类、日期、分支、结论/产出、参考来源
- 新任务归档后，须在下方索引表追加一行
