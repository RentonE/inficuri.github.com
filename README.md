## 儿童足部训练 · 可视化方案

[`foot-training/index.html`](foot-training/index.html) — 单文件、无依赖的可视化训练方案页面：

- 4 个动作的动态 SVG 图解：脚底滚按摩球、扶边单脚站抬脚趾、踩弹力带以脚跟为圆心转半圈、垫瑜伽砖提踵（30 个/组）
- 每个动作附建议剂量、要领与避免事项
- 4 周打卡表（进度保存在浏览器本地），支持打印、深色模式、减少动态效果
