# 项目区（Projects）

**活跃项目**的集中地。后续从本地整合进来的仓库，凡是还在维护/使用的，都放这里，一个项目一个子目录：

```
projects/
├── <项目名A>/
│   └── README.md   # 必须：它是什么、来自哪里、导入日期
└── <项目名B>/
    └── ...
```

## 导入约定

1. **目录名**：小写连字符（`my-tool`，不用 `MyTool` / `my_tool`）
2. **每个项目根下必须有 `README.md`**，至少写清三件事：
   - 这是什么、干什么用
   - 来源（原本地路径或原远程地址）与导入日期
   - 还在维护吗？维护状态一句话
3. **导入前清理**：删掉 `node_modules/`、`dist/`、`build/`、`.DS_Store` 等构建产物和依赖目录，需要时在项目内补 `.gitignore`
4. **保留历史（可选）**：想保留原仓库提交历史用 `git subtree add --prefix=projects/<名> <原仓库> <分支>`；不在乎历史就直接拷文件
5. **大文件**：>5MB 的二进制不要直接提交，用 Git LFS 或放外部存储留链接
6. **项目废弃时**：整体移入归档区——在仓库根目录运行
   `scripts/archive.sh projects/<项目名> "<废弃原因>"`

技能类内容（人物蒸馏等）不放这里，放 `.claude/skills/`（生效）或 `.agents/skills/`（技能本体），见根目录 README。
